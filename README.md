# ✈️ TripVera

Hey! 👋

Thanks for checking out **TripVera**.

TripVera is a React-based travel project built to explore how a modern travel website can bring destinations, trip information, and an interactive user experience together in one place.

The main goal was to practice building a clean travel-focused interface while getting more comfortable with React, reusable components, routing, and handling application data.

---

## ✨ What's Inside?

- ✈️ Travel-focused user interface
- 🌍 Explore different destinations
- 🗺️ Destination and trip information
- ⚛️ React component-based structure
- 🧩 Reusable UI components
- 📱 Responsive design
- ⚡ Fast development with Vite

---

## 🛠️ Built With

- ⚛️ React
- ⚡ Vite
- 💻 JavaScript
- 🎨 CSS
- 🛣️ React Router
- 📦 npm

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/brij018/TripVera.git
```

Move into the project:

```bash
cd TripVera
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in your terminal.

---

## 💭 Why I Built This

I wanted to build something different from the usual practice projects and get more comfortable creating a complete travel-focused interface.

TripVera gave me a chance to work with React components, routing, layouts, and responsive UI while turning a travel concept into an actual working application.

As with most of my projects, the main idea was simple:

**Learn it → Build it → Improve it.** 🚀
